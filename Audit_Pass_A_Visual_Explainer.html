Before / After

Before Pass A

  • Toasts invisible for half the call sites
  • First-user fallback granted owner powers
  • Conversion changes lost on every reload
  • Gemini calls could hang for 540s
  • Square errors leaked stack details to client
  • Empty deprovisionTenant body suspended caller's home tenant
  • Stale tokens bypassed approval gate
  • External signout left tenant data in RAM
  • Super-admin gate keyed wrong claim name
  • Offline fallback resolved to nothing
  • PWA install used blurry/missing icon
  • Migration scripts required forbidden SA keys
  • Re-run created duplicate owner docs

After Pass A (commit 5f28d40)

  • showToast normalizes legacy classes
  • Default role = 'employee', server claim wins
  • markChanged() on every conversion mutation
  • withTimeout(20/45/25s) on all 3 Gemini calls
  • Generic error messages, full detail to console only
  • Body.tenantId required, 400 if missing, 404 if absent
  • getIdTokenResult(true) forces refresh
  • D.* + IDX cleared before login screen reappears
  • superAdmin || role === 'super_admin' check
  • /app.html in PRECACHE, cache version bumped
  • 192 + 512 + maskable icon entries
  • ADC-only init, DRY_RUN by default
  • Deterministic ownerDocId + merge:true
Key Insight
Most bugs were not "wrong logic" — they were missing rails: no timeout on AI, no force-refresh on claims, no precache for offline, no idempotency on migration. The fixes don't add features. They add the guardrails the original code skipped.
